# neon-karma-legal

Privacy Policy and Terms of Service for Neon Karma, published with GitHub Pages:

- https://neon-karma.github.io/legal/privacy/
- https://neon-karma.github.io/legal/terms/

These URLs are referenced by `neon_karma_protocol::compliance::{PRIVACY_POLICY_URL, TERMS_URL}` and must be entered in App Store Connect and Google Play Console.

When the policy changes materially:
1. Edit the page.
2. Bump `PRIVACY_POLICY_VERSION` / `TERMS_VERSION` in the protocol so the game asks players to consent again.

Source of the privacy text: `neon-karma-client/docs/legal/privacy-policy.md`.
